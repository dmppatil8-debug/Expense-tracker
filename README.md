# Expense Tracker

A command-line Expense Tracker built with Python that stores expenses permanently using JSON and supports CSV export.

## Features

* Add expenses
* List expenses by month
* Category-wise spending summary
* Percentage calculation
* Monthly category budgets
* 80% and 100% budget warnings
* Delete expenses by ID
* Export monthly expenses to CSV
* Persistent data storage using JSON
* Handles corrupted JSON files with automatic backup
* Input validation and exception handling

## Technologies Used

* datetime
